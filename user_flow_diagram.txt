  LANE 5 — My Medication Module
  Tab 1: Medicine Reminders   Tab 2: Stock Management
────────────────────────────────────────────────────────────────────────────────

  [SCREEN] My Medication Screen  (TabBar — 2 tabs)
      |
      +------------------------------------+------------------------------------+
      |                                    |
      v                                    v
  TAB 1 — MEDICINE REMINDER           TAB 2 — STOCK MANAGEMENT
  -------------------------           ------------------------
  1. Load medicines from              1. Read medicine stock from
     [SQLITE] LocalDB                    [SQLITE] LocalDB
  2. Group by medicine name           2. Compute stock level:
     (merge duplicates)                  available_stock / (frequency x duration)
  3. Display cards:                   3. Categorise:
     name · disease · times               RED  = Out of Stock
  4. Tap Edit                              ORANGE = Low Stock
     -> MultiDiseaseEditPage               GREEN  = Normal
  5. Tap Delete                       4. Pull-to-refresh to reload
     -> remove from SQLite            5. Tap Edit Stock
     -> cancel alarm                     -> update available_stock in SQLite
                                      6. Tap Add to Cart
                                         -> ShopController -> Orders flow

  ALARM SCHEDULING FLOW               STOCK ALERT FLOW
  ---------------------               ----------------
  A. OCR Scan / Manual Entry          A. App launch
     -> save to SQLite                   -> NotificationService
  B. NotificationService                    .checkAndSendStockAlerts()
     .scheduleAllFromLocal()           B. Query SQLite:
  C. flutter_local_notifications          stock <= alert_before_days threshold
     exact alarm set                  C. One-time local notification
  D. Alarm fires                         per low-stock medicine
     -> AlarmTriggerScreen            D. [BG] WorkManager periodic task
        (full-screen intent)              (background, app closed)
  E. User taps "Taken" / "Snooze"     E. Re-checks stock
  F. SyncService -> push to              -> re-fires notifications if still low
     [FIREBASE] Users/{uid}/medicines

────────────────────────────────────────────────────────────────────────────────
  LANE 7 — Offline-First Architecture
  ConnectivityService · OfflineQueueService · SyncService
────────────────────────────────────────────────────────────────────────────────

  ONLINE                      OFFLINE                     RECONNECT
  ------                      -------                     ---------
  1. ConnectivityService:     1. ConnectivityService:     1. ConnectivityService
     network = online            network = offline            detects network
  2. All Firestore            2. Reads served from           restored
     reads/writes go             [SQLITE] LocalDB         2. SyncService.flush()
     directly               3. Writes queued in              dequeues all ops
  3. SyncService flushes         OfflineQueueService      3. Push SQLite changes
     any pending queue                                        -> Firestore
                                                          4. UI refreshes from
                                                             Firestore

  FIRESTORE COLLECTIONS REFERENCE
════════════════════════════════════════════════════════════════════════════════

  Firestore
  ├── Users/{uid}
  │   ├── Cart/{itemId}
  │   ├── Wishlist/{itemId}
  │   ├── Notifications/{notifId}
  │   └── medicines/{medId}
  │       └── alarms/{alarmId}
  ├── Products/{id}
  │   └── Reviews/{reviewId}
  ├── Categories/{id}
  ├── Subcategories/{id}
  ├── Brands/{id}
  ├── Orders/{id}
  ├── Banners/{id}
  ├── Coupons/{id}
  ├── Admins/{uid}
  └── Announcements/{id}

  Firebase Storage Paths
  ├── banners/
  ├── categories/
  ├── subcategories/
  ├── brands/
  ├── products/
  └── admins/

  Security Rules Summary
  ├── Public read:    Products, Categories, Subcategories, Brands, Banners
  ├── Auth read:      Orders, Coupons, Announcements
  ├── User-scoped:    Users/{uid} + all subcollections
  └── Admin-only write: All catalog data (isAdmin() = exists in Admins/{uid})
